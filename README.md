# IZP

Repozitář k předmětu **Základy programování (IZP)**.

Obsahuje řešení cvičení, projekty a vlastní studijní materiály z přednášek a seminářů.

## Struktura repozitáře

IZP/
├── cviceni/       # Řešení úloh ze cvičení
├── projekty/      # Projekty do předmětu
├── prednasky/     # Poznámky a vlastní materiály z přednášek
├── seminare/      # Poznámky a materiály ze seminářů
├── ostatni/       # Ostatní materiály související s předmětem
├── .gitignore
└── README.md
